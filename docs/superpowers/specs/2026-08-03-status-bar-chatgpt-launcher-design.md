# 状态栏精简与 ChatGPT 7897 启动设计

## 目标

彻底退役通用工具扫描与启动器，只保留配额控制台、用量刷新、专用 ChatGPT 7897 代理启动入口和退出操作。状态栏图标、百分比与状态文字可独立组合显示。

## 范围

- 删除控制台“工具”导航、工具选择页和通用启动面板。
- 删除托盘“已选择工具”子菜单、通用工具扫描及启动命令。
- 配置升级到版本 5，迁移时丢弃旧 `selectedTools` 数据。
- 在 Kimi 与 Codex 两个菜单栏菜单中加入“通过 7897 代理打开 ChatGPT”。
- 在监控设置中加入全局状态栏样式开关：图标、百分比、状态文字。
- 保留每个服务独立的“在状态栏显示”开关。

## ChatGPT 启动契约

启动器直接执行 `/Applications/ChatGPT.app/Contents/MacOS/ChatGPT`，不依赖用户提供的外部脚本。子进程继承以下固定环境：

- `HTTP_PROXY` / `HTTPS_PROXY`: `http://127.0.0.1:7897`
- `ALL_PROXY`: `socks5://127.0.0.1:7897`
- `NO_PROXY`: `localhost,127.0.0.1,::1`
- 同名小写变量与大写变量一致

启动参数固定为：

- `--proxy-server=http://127.0.0.1:7897`
- `--proxy-bypass-list=localhost;127.0.0.1;::1`

ChatGPT 未安装时返回可定位错误；已经运行时拒绝重复启动，避免用户误以为现有进程继承了新代理环境。菜单根据当前状态显示可用或禁用文案。

## 状态栏显示模型

新增 `statusBarDisplay` 配置：

- `showIcon`: 是否显示 Kimi/Codex 图标。
- `showPercentage`: 是否显示 `hNN%` 或 `wNN%`。
- `showStateText`: 是否显示“够 / 偏紧 / 不够 / 未知”。

三个开关全局应用于两个服务，并与 `statusBarServices` 的按服务可见性组合。图标和标题分别设置；关闭标题的两个组成部分时使用空标题。三个开关全部关闭等价于隐藏菜单栏项目，但不会停止后台监控。

## 配置迁移

配置版本升级到 5。版本 4 及更早配置保留账号、监控服务、状态栏服务、代理、凭据和用量事件；旧 `selectedTools` 字段由 Serde 忽略，并在迁移回写后消失。默认显示图标、百分比和状态文字，保持现有用户升级后的可见效果。

## UI

“监控”页保留每个服务的监控与状态栏开关，并增加“状态栏样式”面板。三个复选框支持自由组合，使用文字标签和现有视觉 token，不增加新的图标库或装饰 emoji。
